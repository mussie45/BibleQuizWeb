# 📖 Bible Quiz Web

An interactive Bible quiz website designed to make learning Scripture more engaging through fun questions and challenges.

## ✨ Features

- 📚 Bible quiz questions with different difficulty levels
- 📖 Choose between Old Testament, New Testament, or both
- 🎯 Interactive quizzes with score tracking
- 🏆 Leaderboard to track performance
- 🎨 Clean and responsive user interface

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mussie45/BibleQuizWeb.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser to start playing.

## 🎯 Purpose

To encourage Bible study and help people test and improve their knowledge of Scripture in an enjoyable way.
